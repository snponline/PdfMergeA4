# PdfMergeA4 — รวม PDF / รูป เป็น A4

โปรแกรม Windows สำหรับรวมไฟล์ **PDF, JPG, PNG** เป็น PDF ไฟล์เดียว และปรับ**ทุกหน้าเป็นขนาด A4** เท่ากันหมด
เหมาะกับการเตรียมเอกสารยื่นราชการ เช่น ใบรับรองแพทย์ สำเนาบัตร หรือรูปถ่ายเอกสารจากมือถือ

ไม่ต้องติดตั้ง ไม่ต้องใช้อินเทอร์เน็ต และไม่ส่งไฟล์ออกไปที่ไหน ทุกอย่างทำงานบนเครื่องของคุณ

## ดาวน์โหลด
**[⬇ PdfMergeA4.zip (เวอร์ชันล่าสุด)](https://github.com/snponline/PdfMergeA4/releases/latest/download/PdfMergeA4.zip)**

1. แตกไฟล์ zip ก่อน (คลิกขวา → **Extract All**)
2. ดับเบิลคลิก `PdfMergeA4.exe`
3. ถ้า Windows ขึ้นหน้าจอ *"Windows protected your PC"* ให้กด **More info → Run anyway**
   (ขึ้นเพราะโปรแกรมไม่มีลายเซ็นดิจิทัล)

## วิธีใช้
1. ลากไฟล์ PDF หรือรูปมาวางในหน้าต่าง หรือคลิกเพื่อเลือกไฟล์ จะลากทั้งโฟลเดอร์มาก็ได้
2. เรียงลำดับ: ลากแถวขึ้นลง หรือกด ▲ ▼
3. ถ้ารูปเอียงข้าง กด **↻ หมุน 90°**
4. ดูตัวอย่างหน้า A4 ได้ที่ช่องด้านขวา
5. กด **รวมเป็น PDF (A4)…** แล้วเลือกที่บันทึก

กดปุ่ม **สร้างทางลัด…** ในโปรแกรม จะได้ทางลัดเพิ่ม 2 ที่:
- **ไอคอนบน Desktop:** ดับเบิลคลิกเปิดโปรแกรม หรือลากไฟล์มาวางบนไอคอนได้เลย
- **เมนูคลิกขวา:** คลิกขวาที่ไฟล์ → **Send to → รวม PDF (A4)**
  (บน Windows 11 ต้องกด *Show more options* ก่อน แล้วจึงเลือก Send to)

## ผลลัพธ์
- ทุกหน้าเป็นกระดาษ A4 ย่อหรือขยายให้พอดีหน้า คงสัดส่วนเดิม ไม่ยืดภาพ ไม่ตัดขอบ และวางไว้กึ่งกลาง
- ช่อง **"หน้าแนวนอนใช้ A4 แนวนอน"** (ติ๊กไว้เป็นค่าเริ่มต้น)
  - ติ๊ก: หน้าที่เป็นแนวนอนจะออกมาเป็น A4 แนวนอน
  - ไม่ติ๊ก: ทุกหน้าเป็น A4 แนวตั้ง หน้าที่เป็นแนวนอนจะถูกย่อลงให้พอดีกับหน้าแนวตั้ง
- รูปจากมือถือหมุนตั้งตรงให้อัตโนมัติ รูปใหญ่ถูกย่อให้ด้านยาวไม่เกิน 3000 px เพื่อไม่ให้ไฟล์ใหญ่เกินไป
- PDF ที่เป็นฟอร์มกรอกข้อมูลไว้ ข้อความที่กรอกจะถูกฝังลงในหน้าด้วย ไม่หายไป
- ไฟล์ต้นฉบับไม่ถูกแก้ไข

รองรับไฟล์ PDF, JPG/JPEG, PNG, BMP, TIFF, WEBP
ยังไม่รองรับไฟล์ HEIC จาก iPhone (ถ้าส่งรูปผ่าน LINE จะได้เป็น JPG อยู่แล้ว)

## สำหรับนักพัฒนา

| ไฟล์ | หน้าที่ |
|---|---|
| `pdf_merge.pyw` | หน้าต่างโปรแกรม (tkinter + tkinterdnd2) |
| `pdfmerge_core.py` | ส่วนที่รวมไฟล์ (pypdf, Pillow, pypdfium2) และเก็บเลขเวอร์ชัน `__version__` |
| `shortcuts.py` | สร้างหรือลบทางลัดบน Desktop และใน Send to |
| `build_exe.py` | build exe และไฟล์ zip สำหรับ release |
| `pdfmerge.ico` | ไอคอนโปรแกรม |

```
pip install pypdf pillow pypdfium2 tkinterdnd2 pyinstaller
python pdf_merge.pyw                 รันจากซอร์สโค้ด
python build_exe.py                  ได้ไฟล์ dist\PdfMergeA4.exe และ dist\PdfMergeA4.zip
PdfMergeA4.exe --out out.pdf a.pdf b.jpg   รวมไฟล์โดยไม่เปิดหน้าต่าง (ใช้ทดสอบ exe ที่ build แล้ว)
```

ถ้าโปรแกรมเกิดข้อผิดพลาด รายละเอียดจะถูกบันทึกใน `error.log` ในโฟลเดอร์เดียวกับโปรแกรม

ลิขสิทธิ์ของไลบรารีที่รวมอยู่ใน exe ดูได้ที่ `THIRD-PARTY-NOTICES.txt` ในไฟล์ zip
